# 🦽 在线轮椅租赁系统

一个专为失能老人设计的智能轮椅租赁平台，采用前后端分离架构，提供温暖、简洁、专业的用户界面，让轮椅租赁变得简单便捷。

## ✨ 项目亮点

### 🎨 全新UI设计
- **UI简洁**：采用自然、简洁、专业的设计风格
- **适老化配色**：温暖的医疗蓝绿色调，适合老年用户视觉习惯
- **大字模式**：三档字体大小切换，充分考虑老年用户需求
- **统一视觉语言**：管理端和客户端保持一致的专业风格

### 🚀 核心功能
- **智能搜索**：支持关键词搜索、价格排序、库存筛选
- **一键租赁**：简化的租赁流程，预订单+正式订单双重保障
- **实时库存**：库存自动同步，避免超卖情况
- **订单管理**：完整的订单生命周期管理
- **权限控制**：管理员、操作员分级权限体系
- **操作日志**：完整的操作审计追踪

### 👥 用户角色
- **普通用户**：无需注册，直接浏览租赁，支持大字模式
- **操作员**：库存管理、订单处理、查看日志
- **管理员**：全权限管理，包括用户管理和系统配置

## 🛠️ 技术栈

### 后端技术
- **框架**：Flask 2.0+ (Python Web框架)
- **数据库**：SQLite 3.30+ (轻量级关系型数据库)
- **ORM**：SQLAlchemy (对象关系映射)
- **认证**：Flask-JWT-Extended (JWT令牌认证)
- **跨域**：Flask-CORS (跨域资源共享)
- **加密**：bcrypt (密码安全加密)

### 前端技术
- **框架**：Vue 3 + Composition API (渐进式JavaScript框架)
- **UI库**：Element Plus (Vue 3组件库)
- **状态管理**：Pinia (Vue状态管理)
- **路由**：Vue Router (单页应用路由)
- **HTTP客户端**：Axios (异步HTTP请求)
- **打包工具**：Vite (下一代前端构建工具)
- **图表**：ECharts + Vue-ECharts (数据可视化)

## 🚀 快速开始

### 📋 环境要求
- **Python**: 3.8+
- **Node.js**: 16+
- **npm**: 8+

### 🔧 安装与启动

#### 1. 克隆项目
```bash
git clone <repository-url>
cd WheelRent
```

#### 2. 启动后端服务
```bash
# 进入后端目录
cd backend

# 创建并激活虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # macOS/Linux
# 或
venv\Scripts\activate     # Windows

# 安装Python依赖
pip install -r requirements.txt

# 启动后端服务
python app_simple.py
```

#### 3. 启动客户端（用户界面）
```bash
# 新开终端，进入客户端目录
cd frontend/client

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

#### 4. 启动管理端（后台管理）
```bash
# 新开终端，进入管理端目录
cd frontend/admin

# 安装依赖
npm install

# 启动开发服务器（指定端口避免冲突）
npm run dev -- --port 5174
```

## 🔧 API接口文档

### 客户端API (前缀: `/api`)

#### 轮椅相关
- `GET /api/wheelchair/search` - 搜索轮椅
- `GET /api/wheelchair/detail/<id>` - 获取轮椅详情

#### 订单相关
- `POST /api/order/precreate` - 创建预订单
- `POST /api/order/submit` - 提交正式订单

#### 用户相关
- `POST /api/user/register` - 用户注册
- `POST /api/user/login` - 用户登录
- `GET /api/user/info` - 获取用户信息
- `GET /api/user/address/list` - 获取收货地址
- `POST /api/user/address/add` - 添加收货地址

### 管理端API (前缀: `/api/admin`)

#### 认证相关
- `POST /api/admin/login` - 管理员登录
- `POST /api/admin/logout` - 管理员登出

#### 库存管理
- `GET /api/admin/inventory/list` - 获取库存列表
- `POST /api/admin/inventory/save` - 保存轮椅信息
- `POST /api/admin/inventory/operate` - 库存操作

#### 订单管理
- `GET /api/admin/order/list` - 获取订单列表
- `POST /api/admin/order/update/status` - 更新订单状态
- `GET /api/admin/order/export` - 导出订单数据

#### 用户管理
- `GET /api/admin/user/list` - 获取用户列表
- `POST /api/admin/user/save` - 保存用户信息
- `PUT /api/admin/users/<id>` - 更新用户信息

#### 系统管理
- `GET /api/admin/dashboard/stats` - 获取统计数据
- `GET /api/admin/logs` - 获取操作日志

## ⚠️ 注意事项

### 🔑 启动顺序
1. **首先启动后端服务**（Flask API）
2. **然后启动前端应用**（客户端和管理端可以并行启动）

### 🔌 端口配置
- **后端服务**：5001端口
- **客户端**：5173端口（默认Vite端口）
- **管理端**：5174端口（避免冲突）

### 💾 数据库
- 使用SQLite数据库，数据文件位于`backend/wheelchair_rental.db`
- 首次启动时会自动创建必要的表结构
- 支持数据备份和恢复

### 🔒 安全建议
- 生产环境请修改默认的管理员密码
- 建议使用HTTPS协议部署
- 定期备份数据库和重要数据
